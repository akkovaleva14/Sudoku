# Sudoku

Android-приложение для игры в судоку на Kotlin. Поддерживает генерацию головоломок с единственным решением, сохранение партии и историю результатов.

## Возможности

- Шесть уровней сложности: от Лёгкой до Экстрима.
- Три режима ошибок: проигрыш после первой или третьей ошибки, либо без ограничений.
- Ввод цифр, заметки, стирание и отмена ходов.
- Подсветка связанных клеток, одинаковых цифр и ошибок.
- Пауза, продолжение игры и перезапуск головоломки.
- Логические подсказки: явные и скрытые одиночки.
- Помощь с двумя кандидатами и автоматическое заполнение клеток.
- Автоматическое сохранение текущей партии.
- История побед и поражений с удалением результатов.
- Светлая и тёмная темы, анимации победы и проигрыша.

Подсказка с двумя числами и автоматическое заполнение используют сохранённое решение. Счётчики ошибок и помощи не уменьшаются при отмене ходов.

## Структура

```text
com.example.sudoku/
├── SudokuApplication.kt
├── data/                   # Хранение, JSON и генератор
├── domain/
│   ├── model/              # Модели партии и результатов
│   ├── game/               # Игровая логика и правила
│   ├── hint/               # Анализ подсказок
│   ├── generation/         # Контракт генерации и оценка сложности
│   └── repository/         # Контракты хранения
└── presentation/
    ├── main/               # Activity и переходы
    ├── start/              # Стартовое меню
    ├── game/               # Игровой экран, поле и эффекты
    ├── results/            # История результатов
    └── shared/             # Общее состояние, форматирование и темы
```

## Технологии

Kotlin, Android Views, XML, View Binding, AndroidX Fragment,
ViewModel, Coroutines, StateFlow, RecyclerView, SharedPreferences и Canvas.

## Особенности

- Сложность оценивается по одиночкам и ветвлениям поиска, а не только по количеству исходных чисел.
- Генерация ограничена временем и количеством попыток. При неудаче предыдущая партия сохраняется.
- Данные хранятся локально. JSON-формат версии 4 поддерживает чтение версий 1–4.
- Удалённые результаты не добавляются повторно при сохранении партии.
- Тема выбирается вручную, независимо от системных настроек.

## Запуск

Откройте проект в Android Studio, выполните синхронизацию Gradle
и запустите приложение на устройстве или эмуляторе.

Сборка debug APK:

```bash
./gradlew assembleDebug
```

Для Windows:

```powershell
.\gradlew.bat assembleDebug
```

Требования к JDK и Android SDK указаны в конфигурации проекта.
